ホーム画面への追加方法

「めいじ応援ナビ」をホーム画面に追加すると、次回からはアイコンを押すだけで開けるようになります。アプリのように使えて便利です。追加は無料で、1分ほどで終わります。

iPhoneの方

  1. このページを Safari で開きます。
    LINEの中で開いている場合は、画面右下（または右上）のメニューから「ブラウザで開く」「Safariで開く」を選んでください。
  2. 画面の下にある 共有ボタン（□に↑のマーク） を押します。
  3. 出てきた一覧の中の 「ホーム画面に追加」 を押します。
  4. 右上の 「追加」 を押します。

ホーム画面に「めいじ応援ナビ」のアイコンができれば完了です。

Androidの方

  1. このページを Chrome で開きます。
    LINEの中で開いている場合は、画面右下のメニューから「ブラウザで開く」を選んでください。
  2. 右上の ︙（メニュー） を押します。
  3. 「ホーム画面に追加」（機種によっては「アプリをインストール」）を押します。
  4. 「追加」 を押します。

ホーム画面にアイコンができれば完了です。
